## Importante sobre segurança
O GitHub Pages publica sites estáticos. Nesta versão, usuários, senhas e configurações são armazenados no navegador (`localStorage`). Isso serve para uso individual/protótipo, mas não cria autenticação corporativa real e não sincroniza usuários entre computadores. Para uso por várias pessoas e proteção efetiva, conecte a interface a um serviço de autenticação e banco de dados, como Microsoft Entra ID/Azure, Supabase ou Firebase.
